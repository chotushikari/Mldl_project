# Getting the datasets

The GitHub repository contains code, manifests generated by the code, and measured results. **Raw retinal images are intentionally excluded.** `data/` is in `.gitignore`.

## Download the four public archives

From the repository root, run these commands in a terminal with Python installed:

```powershell
python tools/download_verified.py acrima
python tools/download_verified.py rim_one_r3
python tools/download_verified.py origa_candidate
python tools/download_verified.py refuge_candidate
python tools/verify_figshare_archives.py
```

The downloader resumes interrupted transfers and saves archives in `data/raw/`. The last command compares the two Figshare archives with their published MD5 values. Budget roughly 11 GB of download space for the four archives, plus working space for training.

| Dataset | Source | Local archive | Approximate size |
|---|---|---|---:|
| ACRIMA | [Authors' Figshare article](https://figshare.com/articles/dataset/ACRIMA_Database/7613135) | `data/raw/ACRIMA_Database.zip` | 24 MB |
| RIM-ONE r3 | [University of La Laguna archive](https://medimrg.webs.ull.es/RIM-ONE-r3.zip) | `data/raw/RIM-ONE-r3.zip` | 203 MB |
| ORIGA | [Combined Figshare archive](https://figshare.com/articles/dataset/Retinal_Fundus_Glaucoma_Image_dataset/24549217) | `data/raw/ORIGA_candidate_figshare.zip` | 5.96 GB |
| REFUGE | [REFUGE Figshare archive](https://figshare.com/articles/dataset/REFUGE/26049574) | `data/raw/REFUGE_figshare.rar` | 4.27 GB |

The combined Figshare archive also contains a repackaged REFUGE copy. The project audit compares it with the original-source REFUGE RAR and retrieves official test labels from the RAR. Preserve the official REFUGE train, validation, and test assignments.

After downloading, generate the local manifests:

```powershell
python tools/audit_acrima.py
python tools/audit_rim_one_r3.py
python tools/audit_origa_refuge.py
python tools/audit_refuge_original.py
```

## DRISHTI-GS1

Request access from the [IIIT Hyderabad Medical Image Processing group](https://cvit.iiit.ac.in/mip/datasets.html). Their [terms](https://cvit.iiit.ac.in/projects/mip/drishti-gs/mip-dataset2/Terms.php) prohibit redistribution outside the registered team. Each permitted team member should obtain or receive access under those terms; do not commit the archive or images to this public repository.

## Why the images are not in GitHub

GitHub blocks ordinary Git files over 100 MiB. GitHub Free's LFS per-file limit is 2 GB, smaller than the ORIGA and REFUGE archives. The free LFS storage and monthly download quotas are 10 GiB each, so LFS is also a poor fit for repeatedly sharing this project. Keep source links and download scripts in GitHub; keep datasets in local storage or private team storage where their terms allow it. See [GitHub file limits](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github), [LFS size limits](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage), and [LFS quotas](https://docs.github.com/en/billing/concepts/product-billing/git-lfs).
